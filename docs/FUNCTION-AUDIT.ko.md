## 보호 기준의 근거

- [Apple 온도 안내](https://support.apple.com/en-us/102336)의 10–35°C는 **주변 환경 온도**다. 배터리 센서의 중지값과 바꿔 쓸 수 없다. 통풍 확보가 전제다.
- [Foundation thermalState](https://developer.apple.com/documentation/foundation/processinfo/thermalstate-swift.enum)의 serious/critical은 시스템이 판단한 발열 단계다. Tether는 serious에서 선택한 저전력 완화, critical에서 관리 중인 닫힌 세션 중지를 적용한다. 배터리에서는 기존 지속 발열 제한도 적용한다.
- 배터리 40/43/45°C, 20%, 4시간, 관측 10초는 추가 보호·작업 예산·확인 시간이다. 제조사 안전 보증값이나 수명 개선 실증값이 아니다. 상세 수치와 변경 조건은 [보호 기준](PROTECTION-EVIDENCE.ko.md)에 기록한다.
- [CGGetOnlineDisplayList](https://developer.apple.com/documentation/coregraphics/cggetonlinedisplaylist(_:_:_:))는 절전 중인 화면도 반환할 수 있다. 목록 없음은 절전 증거가 아니다. [CGDisplayIsAsleep](https://developer.apple.com/documentation/coregraphics/cgdisplayisasleep(_:)) 관측은 OS가 보고하는 화면 절전이며 패널 전력 0W 측정이 아니다.

2. 앱 종료·외장 화면 위임에 의한 설정 해제를 **지금 잠자기**로 기록했다. 일반 해제, 사용자 잠자기 요청, OS 잠자기 관측을 분리하고 최근 활동에 앱 연결·종료를 표시한다.

4. 저전력 원복은 명령 종료 코드만 확인했다. 이제 실제 전원 모드를 다시 읽고 원래 값 확인에 실패하면 기록을 보존한다. 실패 전에 ‘복원 완료’를 로그에 남기지 않는다.
