# 모든 Apple Silicon Mac 지원 설계

2026-09-30 사용자 요구 반영. **다음 구현의 필수 지원 기준이며, 현재 설치본에서 전 기종 동작 검증을 마쳤다는 선언이 아니다.**

다음 개발의 공통 기능 계약·우선순위·합격 기준은 [기능 정의](PRODUCT-SPEC.ko.md), 실행기·관측·종료 구조는 [재설계 아키텍처](ARCHITECTURE-REDESIGN.ko.md)를 따른다. 이 문서는 기기별 지원 세부 기준을 보완한다.

노트북 전용 클램쉘과 모든 Mac의 공통 작업 유지를 분리하고, 화면 없는 데스크톱·UPS·원격 앱과의 실제 협력은 [모든 Mac·원격 협력 계약](MAC-REMOTE-COOPERATION.ko.md)을 따른다.

2026-10-01의 미배포 빌드 50 후보는 공통 capability와 데스크톱의 사용자 세션 실행 경로를 사용한다. 도우미 설치 전에도 최신 기기 판정을 적용해 데스크톱·관측 실패·미지원 플랫폼을 구별했다. 설치·원복 34개를 debug와 포장 실행 파일로 확인했지만 실제 데스크톱·UPS와 최소 OS 실행 검증은 남아 있다. [현재 설치 판정과 검증](INSTALL-TARGET-20261001.ko.md).

## 지원 대상

Apple Silicon을 사용하는 Mac 전체를 대상으로 한다. MacBook Air·Pro·Neo와 iMac·Mac mini·Mac Studio·Mac Pro를 포함한다. M1 이후 M 계열의 기본/Pro/Max/Ultra 변형을 모델별 허용 목록으로 제한하지 않고, M 계열 이름이 아닌 Apple Silicon Mac도 제외하지 않는다. Intel Mac은 이번 지원 범위에 포함하지 않는다. [Apple Silicon Mac 목록](https://support.apple.com/en-us/116943)

최소 OS는 **macOS 26 이상**이다. 해당 OS를 실행하는 초기 M1부터의 Apple Silicon Mac을 대상으로 하며 macOS 26 미만은 제외한다. Liquid Glass를 기본 표현으로 사용하고 구버전 OS용 UI 경로는 설계 범위에서 제외한다. [지원 기준과 사용량 조사](MACOS-COMPATIBILITY.ko.md).

초기 M1 Mac의 출시 운영체제는 **macOS 11 Big Sur**다. 출시 OS까지 지원하면 오래된 OS의 지원을 줄이려는 의도와 반대로 범위가 넓어진다. 따라서 초기 Apple Silicon부터의 **기기 범위**와 최소 **OS 버전**을 분리하고, 2026-09-30 지원 하한을 15로 정리했다. 최신 기기를 15로 낮추라는 뜻이 아니며 해당 기종의 OS에서 가용한 API 분기를 사용한다. 모델명으로 향후 모델을 막지 않되 실제 OS/API 동작을 별도로 검증한다. [Apple M1 출시 발표](https://www.apple.com/newsroom/2020/11/introducing-the-next-generation-of-mac/)

## 기기 형태에 따른 기능

| 기능 | Apple Silicon 노트북 | Apple Silicon 데스크톱 |
|---|---|---|
| 앱 실행·업데이트·진단·설정 이관 | 지원 대상 | 지원 대상 |
| 사용자가 시작한 작업 유지 | 지원 대상 | 지원 대상; 공개 유휴 절전 방지 API 사용 |
| 공통 시간 제한 세션·선택한 자동 유지 | 지원 대상; 배터리 시간/잔량 추가 한도 적용 | 지원 대상; 자동 유지는 명시적 opt-in, 초기 off |
| 전원 조건별 닫힌 덮개 유지 | 덮개·배터리 및 실제 제어 능력을 확인해 제공 | 해당 없음; 메뉴와 요청 경로 제외 |
| 배터리 시간·잔량 보호 | 내장 배터리에 적용 | 해당 없음; UPS를 내장 배터리로 해석하지 않음 |
| OS 발열 상태에 따른 자체 유지 중단 | 공개 thermalState 사용 | 공개 thermalState 사용; 배터리 센서 요구하지 않음 |
| 화면 절전·잠금/원격 상태 안내 | 각 기능의 지원·관측 여부를 따로 표시 | 각 기능의 지원·관측 여부를 따로 표시 |
| 다른 앱의 절전 요청 공존 | 자체 요청만 관리 | 자체 요청만 관리 |

데스크톱이 항상 AC라는 이유로 설치·실행 즉시 무기한 유지를 시작하지 않는다. 수동·시간 제한 또는 사용자가 명시적으로 켠 자동 유지에는 공개 `PreventUserIdleSystemSleep` assertion을 사용하고 데스크톱용 `pmset disablesleep`을 만들지 않는다. 이 요청은 화면 절전을 허용하며, 사용자 잠자기 등 모든 잠자기 원인을 막는 기능은 아니다. 따라서 노트북의 닫힌 덮개 유지 드라이버를 이 assertion 하나로 대체하지 않는다. [Apple API 계약](https://developer.apple.com/documentation/iokit/kiopmassertiontypepreventuseridlesystemsleep)

macOS가 이미 제공하는 충전 제어·팬·에너지 모드·잠금 설정을 별도 기능으로 복제하지 않는다. 무잠금 원격 조작과 실제 패널 절전의 동시 동작은 기기/OS/원격 앱별 지원 검증이 필요하며, 전 기종 지원 목표를 근거로 미확인 기능까지 보장하지 않는다.

## 지원 판정 구조

`isSupportedMac = hasBattery && hasLid`를 앱 전체의 입구에서 제거하고 다음을 분리한다.

1. **플랫폼:** Apple Silicon 여부와 OS/API 가용성. 모델명·칩 이름의 문자열 허용 목록에 의존하지 않는다. 배포물은 앱·도우미·CLI·의존 프레임워크의 arm64 포함 여부와 최소 OS를 검사한다.
2. **기기 형태:** portable / desktop / unknown. 센서 조회 실패로 노트북을 데스크톱 또는 미지원으로 바꾸지 않는다. 이미 확인된 기기 특성과 최신 관측 건강 상태를 구분한다.
3. **기능별 지원:** 덮개, 내장 배터리, OS 발열, 화면 관측, 유휴 시스템 유지, 닫힌 덮개 제어, 잠금/원격 상태 관측을 각각 판단한다. `supported`, `notApplicable`, `unavailable`을 구별한다.
4. **현재 관측:** 값·시각·출처·조회 성공 여부를 보존한다. 한 번 못 읽었다고 해당 기종을 미지원 처리하거나 소유 기록을 지우지 않는다.
5. **검증 상태:** 설계상 지원, 모의 시험 확인, 해당 기기 실측 확인을 별도 메타데이터로 둔다. 지원 가능 여부와 테스트 완료를 한 Boolean에 넣지 않는다.

섭씨 센서 키나 팬 유무는 필수 지원 조건으로 쓰지 않는다. 온도 숫자는 선택적 진단으로 남기고 발열 판단은 공개 OS 상태를 따른다. 디스플레이 개수·가상 공급자 ID·독 종류는 칩 세대의 대리 지표로 사용하지 않는다.

Core의 결정 계약은 공통으로 유지한다. 실행기는 공개 유휴 assertion과 관리자 권한이 필요한 닫힌 덮개 변경을 구별한다. 권한이 필요 없는 기능까지 관리자 도우미 설치를 강제하지 않으며, 각 요청의 생성·해제 책임자는 하나로 정한다. UI·CLI·도우미는 동일한 기능 지원 상태를 사용하고 API에서도 해당 없음인 작업을 거절한다.

## 초기 구현에서 찾은 차이

| 초기 코드의 문제 | 보완 기준 |
|---|---|
| `SystemProbe.isSupportedMac`가 내장 배터리+덮개로만 결정 | 플랫폼·기기 형태·기능별 지원으로 분리 |
| GUI `supportedMac`은 시작 시 고정, Helper는 평가마다 재조회 | 동일한 지원 계약과 관측 건강 상태 공유 |
| 데스크톱은 `MacBook이 아님`으로 전체 차단 | 공통 기능 제공, 덮개/배터리 UI만 해당 없음 처리 |
| SafetyReadings가 모든 관리 흐름에 배터리 잔량을 요구 | 배터리 기기와 데스크톱의 필수 보호 입력 분리 |
| 설치·업데이트 경로가 덮개 열림을 전제로 함 | 앱 업데이트는 데스크톱에서 덮개 가드 제외. 도우미 설치는 공통 기기 판정 뒤 MacBook만 두 차례 열림 검사. unknown은 교체 보류. 실기기 검증은 별도 |
| 진단·상태·온보딩에 단일 supported 플래그 사용 | 기능별 원인과 지원 상태를 일관되게 전달 |
| 일반 build 명령은 호스트 아키텍처를 따름 | 출시 산출물의 arm64·최소 OS를 명시적으로 검증 |

현재 가드를 단순히 true로 바꾸면 데스크톱에 무기한 전역 잠자기 금지를 적용하거나 배터리 정보 없음으로 모든 기능을 차단할 수 있다. 실행 드라이버·보호 입력·UI를 함께 바꾸는 작업으로 처리한다.

## 완료 기준

- 모의 시험: 배터리/덮개 있는 기기, 둘 다 없는 기기, 조회 실패, 선택 센서 없음, UPS 연결, 화면 없음/복수 물리/가상/미확인, API 요청 거절, 앱/도우미 종료·복구를 독립적으로 검사한다.
- 노트북: 열린/닫힌 덮개, 두 전원 연결 순서, 배터리 타이머, 물리 외장 화면 위임, 가상 화면, 원격 재접속·잠금 상태를 검증한다.
- 데스크톱: 명시적 시작 전 assertion 없음, 유지 중 화면 절전 허용, 종료 시 자체 assertion 해제, 타 앱 요청 보존, 배터리/덮개 작업 비노출·API 거절을 검증한다.
- OS: 최소 지원 버전 15, 26 및 현재 안정 버전에서 시험한다. 베타 OS 결과를 안정 버전 검증으로 대신하지 않는다.
- 실기기: 초기 M1 노트북, 팬 없는 노트북, 최근 노트북, Apple Silicon 데스크톱을 우선 확보한다. 특정 파생 칩/기종의 표본이 없으면 미실측으로 기록한다. 모든 기종을 직접 시험했다는 표현은 해당 근거가 있을 때만 사용한다.

지원 목표는 전 Apple Silicon Mac이며, 기기 형태에 없는 기능은 자연스럽게 제외한다. 모델을 한 대씩 허용 목록에 추가하는 방식으로 설계하지 않는다.
