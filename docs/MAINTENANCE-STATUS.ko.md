# 유지보수 종료 안내

유지보수 종료일은 **2026-11-11**입니다. 이미 진행 중이던 앱 수정까지만 최종 릴리스로 배포하고, 이후 관리와 지원을 종료합니다.

## 종료 범위

최종 릴리스 이후 신규 기능 개발, 버그 수정, 보안 패치, 새 macOS 버전 호환 지원을 제공하지 않습니다. 추가 업데이트와 업데이트 피드의 지속적인 제공도 보장하지 않습니다.

앱에 남아 있는 업데이트 확인 기능은 기존 정식 단일 서명 피드를 사용합니다. 이 기능이 향후 업데이트나 지원 제공을 약속하는 것은 아닙니다.

## 최종 릴리스와 소스 보존

최종 소스와 GitHub 저장소는 [최종 릴리스](https://github.com/jukqaz/tether/releases)와 함께 읽기 전용으로 보관합니다.

별도로 만든 독립 SwiftUI 레이아웃 시안은 검토용 산출물이며 최종 앱에 적용하지 않습니다. 이번 최종 릴리스에는 그 시안과 별개로 이미 진행 중이던 앱 수정만 포함합니다.

## 배포와 검증의 한계

- 최종 릴리스는 ad-hoc 서명이며 **Developer ID 서명과 Apple 공증이 없습니다**. 파일 무결성을 확인하는 체크섬·업데이트 서명은 Apple 공증을 대신하지 않습니다.
- 실제 Mac의 덮개 닫힘, 전원 분리·재연결, 실제 Sleep/Wake를 포함한 **물리 전원 인수시험은 미완료**입니다. 소스·모의 검사와 설치 화면 검수의 범위를 물리 동작 완료로 확대하지 않습니다.
- 종료 시점의 최소 지원 환경은 Apple Silicon Mac과 macOS 26 이상입니다. 이후 OS·하드웨어·보안 정책 변경에 대한 대응은 제공하지 않습니다.

설치와 기존 사용 방법은 [설치 안내](INSTALL-AND-TEST.ko.md), 확인한 검증 범위는 [검증 기록](VALIDATION-CHECKLIST.ko.md)과 최종 릴리스 설명에서 확인할 수 있습니다.
