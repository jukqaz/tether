# 미배포 소스 수정 · macOS 버전별 UI 호환

- 초기 M1의 출시 OS는 11 Big Sur이지만, 오래된 OS 지원 부담을 줄이기 위해 하드웨어 범위와 OS 하한을 분리한다.
- 배포 대상을 macOS 15로 정하고 26 이상에서 Liquid Glass·스크롤 효과를 사용하도록 가용성 분기를 추가했다. 15에서는 기존 기본 컨트롤을 사용한다.
- 아이콘 컴파일 하한을 앱 메타데이터에서 읽고 앱·도우미·CLI·Sparkle 내부 코드의 arm64/최소 OS 검사와 구버전용 아이콘 누락 검사를 빌드·배포 검증에 추가했다.
- 정식/베타 다운로드 목록은 각 파일의 최소 OS를 개별 표시한다. 이전 26 이상 릴리스를 새 15 이상 릴리스로 잘못 안내하지 않는다.
- macOS 15 대상 컴파일, 업데이트 10개·피드 9개·플랫폼 포장 회귀 6개 통과. 현재 호스트는 macOS 27이며 15 실기기 검증은 아니다. 아이콘 내보내기와 검증용 UI 실행은 현 실행 환경에서 실패했다. [사용량 자료와 상세 제한](MACOS-COMPATIBILITY.ko.md).
- 앱 설치·전원 설정·설정 형식·배포 버전은 변경하지 않았다. 기존 빌드 49 설치 파일의 최소 OS는 그대로다.

앱 기본 외관은 다크 모드와 Liquid Glass다. macOS 기본 사이드바를 사용하고 제목은 고정 영역으로 분리했다. 큰 상태 영역과 글자 크기를 줄이고 설명의 줄 간격을 통일했다. 시스템 화면은 앱 설정·업데이트·점검 순서로 정리하고 진단 세부 정보는 펼쳐 본다. 메뉴바 미리보기는 시스템 → 앱 설정으로 옮겼다. 간단한 메뉴바 패널도 유지 조작과 하단 설정을 두 줄로 나눴다.

## 빌드 36 — 기능에 맞는 조작 컴포넌트

전원 조건은 아이콘과 적용 결과가 있는 세 선택 버튼으로 표현한다. 시간 예약은 자주 쓰는 시간의 직접 선택, 예약 대기 표시, 남은 시간 진행 막대로 구분한다. 설정과 메뉴바가 동일한 예약·연장·종료 컴포넌트를 사용한다. 배터리 잔량과 최대 시간은 나란히 비교하며 자세한 설명은 정보 버튼으로 연다. 앱 설정의 도우미·시스템 상태·진단·고급 관리는 하나의 ‘문제 해결’ 목록으로 묶었다. 기존 정책과 저장 형식은 유지한다.
