# 명령 제한 시간과 실제 종료 확인 — 2026-09-30

명령 실행 경로의 종료 확인 공백을 수정했다. 이전 구현은 제한 시간에 SIGKILL을 보낸 직후 반환했다. 변경 후에는 실제 직접 프로세스의 종료 관측을 제한된 시간 동안 기다리며, timeout과 종료 확인·실제 exit/signal 상태를 별도 결과로 제공한다.

## 변경

- `Shell.Result`에 기존 `status`·`output`과 별도로 `timedOut`, `processID`, `terminationConfirmed`, `exitStatus`를 제공한다. timeout의 호환 상태 124를 실제 SIGKILL 종료 상태와 혼동하지 않는다.
- SIGTERM 유예 0.2초 뒤 필요한 경우 SIGKILL을 보내고, 추가로 최대 0.5초의 종료 확인 시간을 둔다. 종료가 확인되지 않으면 미확인 결과를 반환하며 무기한 `waitUntilExit`를 호출하지 않는다.
- 무한대·NaN 제한 시간은 명령을 실행하기 전에 거부한다.
- 기존 출력 수집·상한·최신 출력 보존 계약과 실패 응답은 유지한다.
