# Tether 이전 V5 명세 안내

현재 기능 범위·기본값·전원/종료 규칙은 **[Tether 기능명세서](PRODUCT-SPEC.ko.md)** 한 곳에서 관리한다.

- [정리 전 V5 원문](archive/2026-10-21-spec-cleanup/PRODUCT-SPEC-V5.ko.md): K00~K09, N01~N41, 당시 표시·선택 보완을 보존한 역사 자료.
- [문서 안내](README.md): 현행 명세·문구·디자인·검증과 과거 조사/실행 기록의 역할.
- [현행 검증 체크리스트](V5-VALIDATION-CHECKLIST.ko.md): 기대 결과와 현재 후보의 실제 인수 근거를 구분.

이 파일은 기존 링크를 위한 안내다. V5 전체 구현·설치·물리 검증 완료를 뜻하지 않으며, 과거 확장 목록을 다시 구현할 지시로 사용하지 않는다. 예전 절 앵커를 찾는 경우 정리 전 원문에서 확인한다.
