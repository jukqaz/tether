# Tether V5 수락·검증 체크리스트

2026-10-21 · [P0 통일 추천안 K00~K09](PRODUCT-SPEC-V5.ko.md)의 문서·화면·검증 계약을 연결했다. **이번에는 명세·표시 문구·체크리스트만 수정했으며 제품 테스트를 새로 실행하거나 앱/웹/설치본을 변경하지 않았다.** 기존 후보의 검사 결과는 [핵심 대조표](FUNCTION-AUDIT.ko.md)에서 범위별로 보존하고 새 P0 통과로 승격하지 않는다.

## 0. P0 계약별 추천 수락 기준

공통 판정은 pass/fail/blocked/not_run/not_applicable이며 아래 신규 P0 실행 판정은 모두 **not_run**이다. 문서 정적 점검과 실행/기기 인수는 분리한다. 경과시간 경계는 주입 가능한 수면 포함 연속 시계로 검사하고, 실제 Sleep·원격 결과는 OS/목적지 관측으로 별도 확인한다.
