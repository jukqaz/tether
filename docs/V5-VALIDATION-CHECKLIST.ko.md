# Tether 검증 체크리스트

2026-10-26 · 기준: [기능명세서 F01~F11](PRODUCT-SPEC.ko.md) · 전원 전용 자동 범위 검증 계획 추가

이 문서는 **무엇을 확인할지**만 관리한다. 실제 통과 수·명령·로그·대상 해시는 [기능 감사](FUNCTION-AUDIT.ko.md)와 연결된 결과 보고서에서 관리한다. 현재 구현 후보의 자동 검증과 나중에 수행할 설치·물리 인수를 구분한다.

## 1. 판정과 근거

- 단계: A 자동/격리, U native UI, I 설치/권한, P 물리/원격, R 실제 업데이트/배포.
- 결과: `pass / fail / blocked / not_run / not_applicable`. 미지원·조건부·권한 대기는 통과가 아니다.
- 기록: 테스트 ID, 기능 ID, 후보/입력 해시·앱/도우미 버전, 실행 조건과 시각, 기대/관측 결과, 원본 로그·화면 경로, 남은 한계.
- 기존 P0의 자동 회귀는 [해당 보고서](../../../outputs/tether-p0-implementation-20261021/RESULT.ko.md)의 정확한 입력과 범위에서만 유효하다. 새 밝기·통계 요약·문구/배치 변경에 일괄 승계하지 않는다.
- 현재 제품 소스의 변경이 없으면 이미 통과한 검사를 이 문서 정리를 이유로 재실행하지 않는다. 실제 UI·설치·물리 인수의 남은 항목은 별도 수행한다.

## 4. 문서 정리의 완료 조건

- F01~F11이 기능명세와 이 체크리스트에 연결되고, 문구·화면 문서가 별도 기능 규칙을 만들지 않는다.
- 현행 문서의 상대 링크·기능 ID·기본값·구현/계획 표시를 점검한다. 과거 결과 파일·SHA·시험 수·판정은 고쳐 쓰지 않는다.
- [정리 전 검증표](archive/2026-10-21-spec-cleanup/V5-VALIDATION-CHECKLIST.ko.md)의 K00~K09, N01~N41, SIMPLE-D01~D08은 당시 수락 계약으로 보존한다. 새 T/P ID의 통과 실적으로 자동 변환하지 않는다.
