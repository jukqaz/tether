# V5 컴팩트 UI 구현 · 2026-10-17

승인한 시안의 메뉴와 설정3탭을 기존 구현 기능에 연결했다. 설치·물리 전원 시험·전원 정책 변경은 이번 범위가 아니다. 원본 작업 상태를 복사한 별도 Git worktree에서 작업했으며 기존 dirty 변경을 초기화하지 않았다.

## 구현한 화면

| 화면 | 변경 |

색은 최신 Graphite+Blue 보드에 맞췄고 고대비는 기존 시스템 대체 색을 보존했다. 본문12pt·보조11pt와 불투명 읽기 표면을 사용한다. 주요 불투명 조합의 계산 대비는 다크 본문13.28:1·보조8.57:1, 밝은 본문15.09:1·컨트롤의 보조5.57:1, 흰 버튼 글자7.65:1이다. 계산 대비는 실제 glass 재질이나 전체 접근성 점수가 아니다.

## 유지한 동작과 범위

- Core/Helper 소스는 작업 시작 해시와 동일하다. 화면 재배치로 전원 분리·배터리2시간·보호·복구 규칙을 바꾸지 않았다.
- 기존 저장값15분/45분 등도 메뉴 선택에서 보존한다. 시간 선택만으로 시작하거나 실행 중 타이머를 재시작하지 않는다.
- 실제 모델이 없는 시안의41개 확장 묶음을 작동하는 옵션처럼 추가하지 않았다. 배터리 한도 확장·분리 승계·다양한 메뉴 구성·클릭 동작 등은 별도 기능 구현 범위다.
- 원본 checkout과 설치 앱·보안·전원 설정은 교체하지 않았다. 생성물은 작업 폴더와 outputs 안에 둔다.

## 검증

- 로컬 앱 패키징과 서명 검증 통과. Xcode 빌드 서비스가 필요한 단계는 승인된 실행 범위로 진행했다. 이번 시험용 패키지는 dSYM을 생성하지 않는다.

검증 중 재개 안내의 버튼명 불일치와 영어 모의 화면의 언어 선택값 불일치를 고쳤다. 후자는 메모리 preview 모델만 수정하며 설치본의 언어 설정을 저장하지 않는다.

## 별도 인수

앱 설치·도우미 인증·업데이트·물리 덮개/전원 분리·실제 Sleep/Wake·장시간 내구성은 실행하지 않았다. macOS26 대상 기기 검증도 별도다. 실행 호스트의 native UI와 macOS26 실기기 증거를 혼동하지 않는다.

GroundLine private profile은 enabled였으나 현재 native artifact/turn 경계를 확인할 수 없어 학습 수락 결과는 unknown으로 남겼다. 구현·검증 결과와 별개이며 임의로 private 기록을 채우지 않았다.

## 2026-10-20 후속 수정 · 자동 시작 안내와 영어 잘림

같은 worktree에서 두 표시 오류를 수정했다. 고급 자동 시작은 전원 연결과 선택한 조건을 모두 요구한다고 안내하고 현재 조건 요약을 표시한다. 모두 중지·보호 중에는 전원 연결만으로 재개된다는 안내를 하지 않는다. 단축키의 native 키 선택기는 번역 문자열의 고유 폭과 최소112pt 배치 공간을 확보한다. 전역 단축키 등록이 비활성인 격리 fixture에서는 표시만 확인하며 실제 OS 단축키 등록의 통과로 확대하지 않는다.

최종 소스 회귀33개와 native 실행기 회귀23개가 통과했고 로컬 후보58 빌드·서명 검증을 마쳤다. 소스 회귀는 메모리 설정·모의 backend이며 물리 전원 근거가 아니다. 자료는 `outputs/tether-v5-ui-fixes-20261020`에 저장한다. `source-freeze.json`에는 이번 대상 파일의 전후 해시, Core/Helper 비교, 설치 앱57의 해시를 남겼다.

정상 `security authorize -u system.privilege.taskport.debug` 요청은 성공했으나 첫 native 실행은 별도 `Enable UI Automation` LocalAuthentication 인증 대기 중60초 후 초기화가 끝났다. 테스트 메서드는 시작하지 않았고 `native-shortcuts/result.json`은 blocked다. 사용자가 정상 UI Automation 인증을 완료한 뒤 `native-final-seven`에서 실제 시험 메서드 실행이 시작됐다. DevToolsSecurity·권한 정의·TCC 정책을 바꾸지 않았다. 인증 성공과 최종 UI 합격은 구별한다.

고유7경로는 영어 단축키 최소 너비, 한국어 최소 창·탭 전환·닫기/재열기, 펼침/접힘 상태의 탭 왕복 보존, 메뉴·설정·진단 갤러리, 오류를 펼친 수동 메뉴의 조작·타이머 보존, 긴 오류의 진단 목적지, 세 탭의 헤더·본문 표시다. 모두 같은 후보58 실행 파일 SHA256 `dc501839bc8c213131c69572f207814e4991a7ef2fb1229cd88253d0cc121dcf`를 사용했다. 각 실행의 테스트 소스 해시와 이전 실패 원본을 보존했고, 실행 중 소스 변경·skip·expected failure·런타임 경고는0이다. 세부 결과는 [검증 요약](../../../outputs/tether-v5-ui-fixes-20261020/verification-summary.json), 화면은 [캡처 색인](../../../outputs/tether-v5-ui-fixes-20261020/header-screen-index.json)에 연결한다.

실제 화살표 아래 빈 공간을 누르던 자동화 좌표를 제목 줄의 측정 위치로 고쳤다. 한 화면에 들어가는 오류 메뉴에 스크롤뷰를 강제하던 기대값은 버튼 가시성·겹침·타이머 ID/기한 보존으로 교정했다. native 시간 팝업 선택 뒤 같은 More 버튼의 접근성 이름이 ‘다른 동작’에서 ‘더 보기’로 바뀌는 경우는 정확한 ID·역할·허용한 목적 이름으로 검증하며, 메뉴 종료를 기다린 뒤 다음 조작을 진행한다. 검사 종료 전 `hasSucceeded`를 읽어 성공 경로에서도 실패용 자료를 수집하던 실행기 문제는 실제 `totalFailureCount` 기준으로 고쳤다. 이 보정 때문에 이미 통과한 경로를 전체 반복하지 않았다.

PNG와 geometry를 함께 검수했으며 헤더 뒤 본문 비침·잔상·고정 조작 겹침은 발견하지 못했다. 읽기 영역 경계에서 본문 일부가 잘리는 것은 실제 스크롤의 클리핑으로 구분한다. 자동 시작 상단 한 장에는 하단 일부를 가리는 작은 외부 팝업이 있어 그 캡처만으로 본문을 평가하지 않았고, 같은 내용이 온전히 보이는 중간·끝 캡처로 확인했다. 팝업의 출처나 제품 오류를 추정하지 않았다.

이 결과는 macOS27.0.1/Xcode27.1에서 모의 전원·메모리 설정을 사용하는 격리 앱의 실제 UI 검증이다. OS 전역 단축키 등록, 설치·도우미 교체, macOS26 실기기, 물리 덮개/전원 분리·잠금·Sleep/Wake는 확인하지 않았다. 설치 앱57은 바꾸지 않았다. 현재 owner-private 학습 프로필은 enabled이나 이 단위의 native artifact/turn 소유 근거가 없어 학습 등록은 unknown으로 남기고 수락·비용을 소급해서 만들지 않았다.
