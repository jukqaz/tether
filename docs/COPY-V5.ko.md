# Tether 표시 문구

이 문서는 쉬운 용어와 상태별 표시 문구를 관리한다. 기능 규칙·기본값·지원 조건은 [기능명세서](PRODUCT-SPEC.ko.md)가 우선한다.
화면 구성은 [정보 구조](DESIGN-V5.ko.md), 색·서체·간격은 [스타일 가이드](../DESIGN.md)를 따른다.
문구가 정리됐다는 사실은 실제 앱 반영·설치·화면 검수·밝기 0 동작 검증 완료를 뜻하지 않는다.
정리 전 문구와 기록은 [보관 문서](archive/2026-10-21-spec-cleanup/COPY-V5.ko.md)에 남긴다.

## 기록·다른 앱·업데이트

| 상태·항목 | 표시 문구 |
|---|---|
| 통계·기록 빈 상태 | 아직 기록이 없어요 |
| 조회 중 | 기록을 불러오는 중 |
| 기록 조회 실패 | 기록을 불러오지 못했어요 · 다시 확인 |
| 다른 앱의 실제 요청 관측 | 다른 앱의 잠자기 방지 요청 {개수}개 |
| 다른 앱 상세 | 앱 또는 프로세스 / 컴퓨터 잠자기 방지 또는 화면 꺼짐 방지 / 확인 시각 / 앱 열기 |
| 다른 앱 요청 조회 실패 | 다른 앱의 요청을 확인하지 못했어요 |
| 업데이트 채널 | 정식 / 정식 + 베타 |
| 업데이트 확인·결과 | 업데이트 확인 중 / 최신 버전이에요 / {버전} 업데이트 가능 |
| 업데이트 확인 실패 | 업데이트를 확인하지 못했어요 · 다시 확인 |
| 설치 보류 | 업데이트 설치 대기 중 · {확인된 이유} |

예시의 이유·시각·개수는 실제 확인값으로 채운다. 선택됨·적용 중·확인됨을 같은 문구로 표시하지 않는다.
`최신 버전이에요`는 선택한 채널의 업데이트 조회가 성공했을 때만 쓴다. 조회 실패·과거 결과를 최신 확인으로 표시하지 않는다.
자동 시작 꺼짐·자동만 쉬기·타이머 끝내기·모두 중지는 대상과 결과가 다르므로 같은 중지 문구로 합치지 않는다.
다른 앱은 실제 요청을 관측한 경우에만 표시하며 조회 실패를 0개로 바꾸지 않는다. 앱 연결이 확인되지 않으면 `앱 열기`를 숨긴다.

## 확장 옵션 문구 · 2026-10-29

기능명세 §9의 옵션 범위에 맞춘 추가 문구다. 아직 화면에 적용한 결과가 아니다. 기존 전원 전용 안내는 기본 모드에서 사용하고, 고급 규칙을 켠 상태를 전원 전용처럼 표시하지 않는다.

| 항목·내부 표현 | 사용자 표시 |
|---|---|
| 고급 설정 노출 | 추가 옵션 보기 · 기능을 켜지 않고 설정 항목만 펼칩니다 |
| 현재 작업 값 | 이번 작업에만 적용 |
| 기본값 변경 | 다음에 시작할 작업의 기본값 |
| 규칙 값 | 이 자동 규칙에만 적용 |
| AND / OR | 모든 조건이 맞으면 / 하나라도 맞으면 |
| manual override | 수동으로 시작하면 자동은 잠시 쉬기 |
| extend by N | {N}분 추가 · 현재 종료 시각에 더합니다 |
| stop in N | 지금부터 {N}분 뒤 종료 · 기존 종료 시각을 바꿉니다 |
| 작업 수명 | 앱이나 작업이 끝날 때까지 |
| hook | 이 일이 생기면 실행 |
| lease | 외부 도구가 요청한 유지 · {남은 기한} |
| heuristic / verified | 활동으로 추정 / 연결 확인됨 |
| 미지원·권한·실패 | 이 Mac에서는 지원하지 않음 / 사용하려면 준비 필요 / 적용하지 못함 |
| 부가 기능 활성 요약 | 추가 기능 {개수}개 사용 중 · {핵심 요약} |

활동 유지 OFF·밝기 0·화면 절전·잠금 옵션 OFF를 `잠기지 않음`으로 바꾸지 않는다. shell 명령이나 프로세스 식별값 같은 기술 용어는 해당 고급 편집 화면에서만 표시한다. 지원 미확인 기능에 활성화 스위치를 먼저 보여주지 않는다.
