# macOS 호환성과 버전 사용량 조사

2026-10-06 사용자 결정: **최소 지원 OS를 macOS 26 이상으로 변경한다.** Apple Silicon Mac이 대상이며 Liquid Glass를 기본 표현으로 사용한다. macOS 26 미만의 실행·UI fallback은 앞으로의 제품 지원 범위에서 제외한다.

현재 기준은 [기능 정의](PRODUCT-SPEC.ko.md)와 [재설계 구조](ARCHITECTURE-REDESIGN.ko.md)다. Package.swift, 앱 LSMinimumSystemVersion, 런타임 지원 판정과 안내 문구를 26으로 맞춘다. 배포별 최소 OS는 각 서명된 설치 파일의 기존 메타데이터를 보존하며 과거 릴리스·설치본을 소급 수정하지 않는다.

이 하한 변경은 물리 클램쉘·무잠금·원격 사용의 실기기 합격을 뜻하지 않는다. macOS 26과 최신 지원 OS, 초기/최근 Apple Silicon 노트북 및 데스크톱을 별도로 검증한다.

## 이전 조사·검증 기록: 2026-09-30

아래는 당시 macOS 15 하한을 선택했던 연구·검증 기록이다. 사용량 집계는 재조회하지 않았으며 현재 하한 결정과 지원 완료의 근거로 사용하지 않는다.

2026-09-30 조사·구현. 현재 개발 소스의 최소 배포 대상은 **macOS 15 Sequoia**다. **26 이상에서는 Liquid Glass, 15에서는 기본 macOS 컨트롤**을 사용한다. 컴파일과 메타데이터 검사를 통과한 상태이며 구버전 실기기 지원 인증이나 새 릴리스 게시를 뜻하지 않는다.

## 지원 기준

| OS | UI | 이번 확인 범위 |
|---|---|---|
| macOS 15 Sequoia | 기본 재질·색상 표면·테두리 버튼 | 배포 대상 15.0 컴파일 확인; 실제 15 실행 미확인 |
| macOS 26 Tahoe 이상 | Liquid Glass·새 스크롤 효과 | 기존 표현 유지; 이번 변경 후 실제 화면 확인 미완료 |
| macOS 14 이하 | 이번 지원 대상 밖 | 초기 M1 출시 OS인 11까지의 하위 호환은 제공하지 않음 |

전원 정책·설정 형식은 OS별로 복제하지 않는다. UI 호출 지점에 `#available(macOS 26.0, *)`를 적용하고 같은 내용·조작을 두 표현에서 공유한다. 구버전 사용자에게 호환 모드 스위치를 요구하지 않는다.

처음에는 기존 API로 14까지 컴파일되는지 확인했지만, 불필요하게 오래된 OS 지원을 늘리지 않으려는 사용자 요청을 반영해 **제품 하한은 15**로 올렸다. 초기 M1의 출시 OS는 macOS 11 Big Sur이므로 그 출시 OS를 하한으로 쓰면 지원 범위가 오히려 넓어진다. 초기 M1부터의 기기 지원과 OS 하한은 별도 기준이다. 14 이하 사용자가 없다는 판단은 아니며, 유지보수·실기기 검증 범위를 줄이기 위한 선택이다. [Apple M1 출시 발표](https://www.apple.com/newsroom/2020/11/introducing-the-next-generation-of-mac/)

앱 실행 하한과 빌드 도구의 실행 하한은 다르다. 빌드는 macOS 26 이상 SDK와 Icon Composer를 포함한 Xcode 26 이상을 사용한다. 선택한 Xcode의 호스트 OS 요구 사항을 충족해야 한다. 예를 들어 Xcode 26은 macOS 15.6 이상을 요구한다. [Apple Xcode 요구 사항](https://developer.apple.com/documentation/xcode-release-notes/xcode-26-release-notes)

모든 Apple Silicon **기종**을 대상으로 한다는 요구와 모든 과거 OS를 지원한다는 요구는 구별한다. 최근 기기를 macOS 15로 낮추라는 뜻이 아니다. 데스크톱의 배터리·덮개 없는 경우를 처리하는 지원 구조는 [별도 설계](APPLE-SILICON-SUPPORT.ko.md)에 남아 있으며 이번 UI 분기로 완료되지 않는다.

## 사용량 자료와 해석

9월 30일 조회 시 아래 자료의 최신 공개 집계는 8월까지였다. 분모·표본·누락 범위가 달라 서로 평균을 내거나 전체 Apple Silicon Mac의 점유율로 바꾸지 않았다.

| 자료 | 관측 기간·표본 | 확인한 내용 | 지원 결정에 쓸 수 있는 범위 |
|---|---|---|---|
| [TelemetryDeck Orbital Survey](https://telemetrydeck.com/survey/apple/macOS/versions/) | 2026-08-24 주간; 해당 SDK를 사용하는 앱 표본 | 공개 상위 10개 버전의 합 안에서 14 약 0.67%, 15 약 10.67%, 26 약 87.30%, 27 약 1.37% | 15 이용이 남아 있음을 확인. 전체 Mac 또는 Apple Silicon 전용 점유율은 아님 |
| [Steam Hardware Survey, Mac Only](https://store.steampowered.com/hwsurvey/?platform=mac) | 2026-08; 자발적으로 참여한 Mac 게임 사용자 | 표시된 26.x 합계 58.23%, 27.x 3.86%, 15.x 5.58%, Other 32.32% | 표시된 항목만으로 26 이상은 최소 62.09%. Other가 커서 정확한 14+/15+/26+ 비중 계산 불가 |
| [Statcounter](https://gs.statcounter.com/os-version-market-share/macos/desktop/) | 2026-08; 웹 이용 기반 | 제공자가 Catalina 이후 버전 식별 오류를 명시 | 세부 OS 지원 비중 계산에서 제외 |
| [Omni Software Update Statistics](https://update.omnigroup.com/) | 참여한 Omni 고객 일부; 현재성 확인 불가 | 공개 메뉴의 OS 구분이 10.11 등 과거 버전에 머무름 | 14·15·26의 최신 사용 비중 근거로 채택하지 않음 |

TelemetryDeck의 다운로드 JSON은 `topN`, `threshold=10`, 주간 단위, `clientUser`에 대한 `thetaSketch` 추정 집계를 사용한다. 위 비율은 **공개된 10개 버전별 추정 사용자 수의 합**을 분모로 직접 합산한 값이다. 원본 차트도 이 10개 합을 100%로 표시한다. 전 세계 고유 Mac 수, 전체 SDK 이용 Mac 수 또는 14 이상 지원율 100%라는 뜻이 아니다. 버전 갱신·여러 앱 이용에 따른 사람/기기 중복 여부까지 이 공개 자료로 해소할 수 없다. [공개 JSON](https://cdn.sanity.io/files/8botbl6i/production/fb023e7cd7fdb6b7c872ad5bdcaf624132807dec.json)

자료의 마지막 버킷은 8월 31일이지만 쿼리는 8월 말에 끝난다. 주간으로 비교할 수 있는 8월 24–30일을 표에 사용했다. 숫자는 반올림해 합계가 100%와 소폭 다를 수 있다. TelemetryDeck은 기술 친화적인 독립 개발자 앱과 미국·유럽 편향, 표본 증가에 따른 변동을 직접 설명한다. 전체 서비스의 앱 수·월간 사용자 수를 macOS 표본 수로 전용하지 않는다. [표본 편향 설명](https://telemetrydeck.com/survey/apple/surveyBiases/)

Steam의 `Other`에는 표시되지 않은 최신 패치 버전도 들어갈 수 있다. 이를 모두 구버전으로 분류하지 않는다. 위 두 자료 모두 공개 표에서 **Apple Silicon만을 분리한 OS 교차분포**를 확인하지 못했다.

**판단:** 26 전용 제한을 유지하면 여전히 사용되는 15 환경을 제외한다. 15 사용을 남겨 두고 구형 OS의 지원·검증 부담을 줄이기 위해 15를 하한으로 선택했다. 이는 구현 비용과 관측된 수요를 함께 고려한 제품 결정이며, 전 세계 사용자의 특정 비율을 보장하는 통계 결론은 아니다.

## 빌드·업데이트 보완

- `Package.swift`와 앱 `LSMinimumSystemVersion`을 15.0으로 맞췄다. 아이콘 컴파일도 앱 메타데이터에서 하한을 읽는다.
- 앱·도우미·CLI와 Sparkle 내부 코드의 arm64 포함 여부 및 실제 Mach-O 최소 OS를 검사한다. 중첩 번들의 최소 OS와 구버전용 ICNS 헤더·아이콘 카탈로그 존재도 대조한다. 아이콘 모양이나 구버전 렌더링 성공을 이 검사로 판정하지 않는다.
- 이 검사를 `build.sh`와 릴리스 ZIP 검증에 연결했다. Info.plist만 15로 낮춘 채 도우미가 26을 요구하는 잘못된 포장을 거절한다.
- 피드와 다운로드 목록은 **각 릴리스의 최소 OS**를 유지한다. 예전 26 이상 정식판과 새 15 이상 베타판이 섞여도 두 파일의 요구 사항을 따로 표시한다. 기존 설치 파일이나 서명된 피드를 소급 수정하지 않는다.
- CI는 최신 SDK를 사용할 수 있는 기존 macOS 26 빌드 환경을 유지하며 포장 회귀 검사를 추가했다. 이 CI가 macOS 15에서 실행된다는 뜻은 아니다.

## 이번 검증 결과

검증 호스트는 macOS 27.0 (26A428), 사용 SDK는 macOS 27.0이다. 최신 SDK로 낮은 배포 대상을 컴파일한 결과와 해당 구버전에서 직접 실행한 결과를 구별한다.

| 검사 | 결과 |
|---|---|
| macOS 15 대상 SwiftPM 앱·도우미·CLI 빌드 | 통과. 남아 있던 26 전용 스크롤 API도 분기 후 컴파일 |
| Swift 업데이트 동작 회귀 | 10개 통과 |
| 정식/베타 피드 회귀 | 9개 통과. 서로 다른 OS 하한 보존·불일치 거절 포함 |
| 실제 Mach-O를 사용한 포장 회귀 | 6개 통과. 높은 도우미 하한·Intel 전용 중첩 실행 파일·잘못된 중첩 메타데이터·아이콘 누락 거절 |
| 검증 번들의 실제 실행 파일 메타데이터 | 8개 통과. Tether 3개는 15.0, Sparkle 5개는 12.0; 모두 arm64 포함 |
| macOS 15 실행·실제 Liquid Glass/대체 UI 화면 | 미확인 |
| 새 아이콘 내보내기·완성된 신규 릴리스 ZIP | 미완료 |

앞선 macOS 14 대상 아이콘 컴파일은 `Icon export exited with status 255`로 실패했고 같은 출력에 CoreSimulator 서비스 연결 실패가 기록됐다. 최소 OS 때문에 실패했다고 단정하지 않는다. 15로 하한을 올린 뒤에는 코드 빌드·회귀·메타데이터 검사를 다시 실행했으며 아이콘 내보내기와 UI 실행은 재시도하지 않았다. 검증용 번들은 기존 아이콘을 복사해 코드 메타데이터만 확인했으며 이를 새 포장 성공으로 계산하지 않았다.

앞선 별도 검증 번들의 `open -W -n` 실행은 `kLSNoExecutableErr (-10827)`로 실패했다. 실행 파일 존재·실행 권한·arm64 형식·서명·Info.plist 문법은 확인했으나 LaunchServices 실패 원인은 확정하지 못했다. 따라서 대체 UI 화면을 직접 확인했다고 하지 않는다.

다음 배포 전에는 15의 실제 실행과 메뉴바·설정 UI, 26 이상의 Liquid Glass, 구버전 아이콘 및 업데이트 설치 경로를 확인해야 한다. 현재 설치된 앱·도우미, 전원/잠금 설정, 설정 형식, 릴리스 버전은 이번 작업에서 변경하지 않았다. 이전 빌드 49의 물리 시험 결과를 새 OS에서의 통과로 재사용하지 않는다.
