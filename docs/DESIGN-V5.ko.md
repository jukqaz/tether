# Tether 화면 정보 구조

단일 메뉴와 사이드바 설정 4페이지의 배치·접힘·스크롤·상태 표시를 관리한다.
기능 규칙·기본값은 [기능명세서](PRODUCT-SPEC.ko.md), 문구는 [표시 문구](COPY-V5.ko.md), 시각 표현은 [스타일 가이드](../DESIGN.md)를 따른다.
이 문서는 실제 UI·설치·밝기 0 검증 완료를 주장하지 않는다. 정리 전 자료는 [보관 문서](archive/2026-10-21-spec-cleanup/DESIGN-V5.ko.md)에 남긴다.
현재 소스는 전원 중심 기본 자동 모드를 사용하고, 설정을 `전원·덮개 / 수동 유지 / 보호·진단 / 일반`으로 나눈다. 과거 3탭 시안·생성 PNG와 현재 화면은 구분한다.

2026-10-29에는 기능명세 §9의 O01~O26을 선택적 고급 기능 범위로 포함하고 native 구현을 시작했다. 아래 표에는 후속 후보도 포함되어 있으므로 실제 연결 여부는 [Native 구현 상태](PRODUCT-SPEC.ko.md#native-구현-상태--2026-10-29)를 우선한다. 현재는 단일 메뉴와 설정 4페이지를 사용하고 추가 옵션은 검색·상세 화면으로 분리한다. 시안 사이트와 설치본의 검증 상태는 별도 결과 보고서를 따른다.

## 현재 옵션의 배치 · 2026-11-07

실제 연결된 조작을 기본 화면과 상세에 나눈다. 구현 후보는 기능명세 §9의 지원 상태를 따르며, 이 표를 구현 완료 목록으로 대신하지 않는다.

| 위치 | 기본 화면 | 추가 선택·상세 |
|---|---|---|
| 메뉴 현재 작업 | 확인된 상태·이유, 수동 남은 시간·30분 연장·수동 종료 | 현재 작업의 적용 범위·문제 원인 |
| 메뉴 새 시작 | 30분·1시간·2시간 등 허용된 시간 선택과 시작 | 다른 시간·종료 시각은 별도 초안에서 명시적으로 시작. 현재 타이머와 동시에 편집하지 않음 |
| 메뉴 빠른 조작 | 자동만 쉬기/재개, 덮개 허용, 열린 화면 켜두기 | 전원 분리 결과 요약·관련 설정. 전체 중지·보호 때 실행 불가능한 조작은 숨김 |
| 메뉴 전원 상세 | 필요할 때 펼치는 배터리·전원 정보 | 충전기 정격 출력과 실제 배터리 충전·방전 전력을 구분; 미제공 값은 추정하지 않음 |
| 전원·덮개 | 자동 시작·전원 분리·화면/덮개 허용·현재 적용 결과 | 도우미, 닫힌 화면 선택, 추가 자동 조건·프리셋 |
| 수동 유지 | 다음 수동 작업의 기본값·전원 범위·배터리 한도 | 알림·종료 동작·작업 연결 등 지원된 선택 |
| 보호·진단 | 열·잔량·저전력 보호 | 보호 후 재개, 사용 통계·최근 동작·다른 앱 요청·로그와 보고서 |
| 일반 | 로그인·언어·메뉴 표시·업데이트 | 알림·설정 가져오기/내보내기·추가 옵션 |

옵션이 많은 그룹은 **상세 화면으로 이동**하고 본문에 요약값을 남긴다. 같은 기능 안의 짧은 선택만 펼침에 둔다. 펼침 안에 여러 펼침을 중첩하지 않는다. 상세 화면은 제목·뒤로 가기와 단일 본문 스크롤을 사용한다. 설정 검색은 쉬운 이름과 유사어로 그룹·옵션을 찾고 정확한 위치로 이동한다.

`이번 작업만 / 다음 작업 기본값 / 이 자동 규칙 / 앱 전체`는 편집 화면 제목 또는 그룹 위에 한 번 표시한다. 각 행에 반복 배지를 붙이지 않고 예외인 행만 범위를 추가한다. 현재 적용값과 저장된 기본값이 다르면 해당 편집 화면에서만 구분한다. 기본값 변경이 현재 타이머를 새로 시작하는 것처럼 보이지 않게 한다.

자동·수동·전원 분리·전체 중지·보호 상태의 메뉴 틀은 하나다. 현재 작업 요약·작업 조작·다음 행동의 순서를 유지하며 상태별로 필요한 내용만 바꾼다. 타이머가 끝나도 자동이 남는 경우만 짧은 조건부 설명을 둔다. 메뉴와 설정에 같은 긴 설명을 반복하지 않는다.

켜진 고급 기능·기다리는 권한·도우미 오류·복구 실패는 그룹을 접어도 요약으로 보인다. 단순 미지원은 기본 화면을 채우지 않고 고급 목록에서 이유를 확인할 수 있게 한다. `고급 기능 표시`는 노출만 바꾸며 실행·권한 요청·설정 초기화가 되지 않는다. 기능군 O01~O26을 화면 검수의 누락 확인 단위로 사용한다.

색·글자·행 높이는 [스타일 가이드](../DESIGN.md)의 역할별 기준을 따른다. 그래파이트 + 블루, 불투명 읽기 표면, 표준 macOS 컨트롤을 사용한다. 한글·영어, 밝음·어두움, 헤더·본문 분리를 검수하고 소스 치수와 실제 화면의 조작 결과를 기록한다.

## 단일 메뉴

| 순서 | 기본 표시 | 접힌 상세·연결 |
|---|---|---|
| 현재 상태 | 상태 아이콘·짧은 상태·확인된 이유 | 긴 이유·확인 시각 |
| 현재 타이머 | 남은 시간·끝날 시각·연장·타이머 끝내기 | 현재 작업에 필요한 추가 설명 |
| 새 직접 시작 | 시간 선택기·직접 시작 | 기능명세 F01에서 정한 고급 시간 선택 |
| 빠른 선택 | 덮개를 닫아도 계속 사용·열린 덮개의 화면 켜두기 | 전원 분리 결과·실제 적용 상태·관련 설정으로 이동 |
| 자동만 쉬기 | 현재 쉬는 상태·자동 재개 | 기능명세 F02의 선택값 |
| 하단 조작 | 모두 중지 또는 다시 허용·설정·더 보기 | 잠자기·앱 종료 |

자동과 수동의 이유·남은 시간은 각각 한 번 표시한다. 실행 중 수동 타이머가 있으면 새 타이머 선택기 대신 현재 타이머 조작을 보여준다.
덮개 세부 화면 선택은 설정이나 하위 선택에 둔다. 세 선택을 큰 설명 카드로 나란히 늘어놓지 않는다.
전원·덮개·원격 상황은 보조 정보이며 보호·실패·중지 상태를 대신하지 않는다. 원격 전용 메뉴는 만들지 않는다.
메뉴에는 전체 작업 목록·상세 프로세스 식별값·항상 보이는 진단 배지를 두지 않는다.

## 설정 4페이지

| 페이지 | 먼저 표시 | 접힌 상세·별도 진입 |
|---|---|---|
| 전원·덮개 | 전원 연결 자동 시작·전원 분리 정책·화면/덮개 허용·도우미 | 닫힌 화면 선택, 적용 범위, 추가 조건·프리셋 |
| 수동 유지 | 다음 수동 기능·전원 범위·배터리 시간 한도 | 저장·적용 범위, 작업 연결 안내 |
| 보호·진단 | 열·잔량·저전력 보호 | 보호 후 재개·사용 통계·최근 동작·다른 앱 요청·로그와 보고서 |
| 일반 | 메뉴 표시·로그인·언어·업데이트 | 알림·설정 가져오기/내보내기·추가 옵션 |

메뉴와 설정의 같은 항목은 같은 저장값과 확인 결과를 읽는다. 어느 화면에서 바꾸었는지에 따라 별도 정책을 만들지 않는다.
현재 작업과 다음 기본값에 적용하는 범위는 기능명세 F04~F05를 따른다. 선택 편집이 기존 작업의 기한·전원 범위를 새로 만드는 조작처럼 보이지 않게 한다.
수동 유지에서 앱 전체 전원·덮개 허용이 필요하면 전원·덮개 페이지로 연결한다. 같은 전체 스위치와 분리 정책 편집기를 여러 페이지에 반복하지 않는다.
전원·덮개 페이지는 자동 시작과 전원 분리를 구분한다. 앱·장비·네트워크 조건과 조건 조합·프로필 편집은 추가 조건 상세로 분리한다. 기본 자동 모드에서 배터리의 새 자동 시작은 없고 직접 시작한 타이머와 F03의 허용된 계속만 가능함을 짧게 표시한다.
기존 비전원 규칙이 실행 중인 이관 상태에서는 해당 사실과 전원만으로 전환하는 조작을 숨기지 않는다. 데이터 보존을 숨은 조건 실행으로 구현하지 않는다.
덮개 하위의 `덮개를 닫으면 내장 화면을`은 주 스위치 가까이에 둔다. 열린 화면 켜두기와 닫힌 내장 화면 선택의 범위를 짧게 구분한다.
기기에서 제공할 수 없는 항목의 표시·숨김 기준은 기능명세를 따르고, 준비 필요와 실행 실패를 서로 다른 상태로 보여준다.
사용 통계·최근 동작·다른 앱 요청·로그와 보고서는 보호·진단 페이지에서 진입한다. 기간·조회 결과·빈 상태·실패를 해당 화면에 표시한다.

## 접힘과 스크롤

- 기본 화면은 현재 결과와 가능한 다음 조작부터 보여준다. 긴 원인·고급 선택·진단은 가까운 펼침에 둔다.
- 기능을 끄면 그 기능의 세부값을 접고 선택 요약과 편집 진입을 남긴다. 접는 동작이 선택 삭제나 기능 실행이 되지 않게 한다.
- 기본 화면에서 항목을 접거나 숨기는 것은 기존에 저장한 고급 선택의 삭제·OFF 명령이 아니다.
- 선택 상태·펼침 화살표·실제 자식 컨트롤의 노출을 일치시킨다. 펼침 안에 같은 주상태나 종료 버튼을 복제하지 않는다.
- 보호·해제 미확인·설정 복구 실패와 해결 진입은 접힘 밖에서도 보인다.
- 메뉴는 본문만 스크롤하고 하단 주요 조작을 유지한다. 설정은 사이드바·고정 제목 아래 본문 한 곳만 스크롤한다.
- 본문이 제목 뒤로 비치거나 겹치지 않게 자른다. 긴 설명은 줄바꿈하고 좁은 행의 컨트롤은 아래로 옮긴다.
- 탭 전환·상세 펼침·창 재열기에서 현재 선택과 조작 위치를 보존한다. 긴 내용의 마지막 조작까지 접근할 수 있어야 한다.

## 상태 표시

상태 판정과 동작 가능 여부는 기능명세 F01~F07을 따른다. 이 문서에서 별도 실행 우선순위를 만들지 않는다.
표시는 확인된 보호·실패·복구 필요를 먼저, 이어서 중지·확인 중·실행·대기를 보여준다. 함께 유효한 이유는 보조줄에 남긴다.
저장된 스위치 ON을 현재 실행으로 칠하지 않는다. 선택값과 실제 적용 상태를 가까이 구분한다.
밝기 0은 재조회로 확인한 경우에만 적용됨으로 표시한다. 화면 꺼짐·잠금 해제·원격 성공 배지로 대체하지 않는다.
자체 잠자기 방지 해제, 원래 설정으로 되돌리기, 잠자기 요청, 실제 잠자기 확인은 별도 결과로 표시한다.
시작·연장·재개를 사용할 수 없으면 확인된 이유를 같은 영역에 짧게 표시한다. 오류 원문 전체는 상세에서 읽을 수 있게 한다.

## 다른 앱 요청과 문제 확인

`다른 앱의 잠자기 방지 요청`은 보호·진단 페이지에서 상세로 진입한다. Tether 중지 후 다른 요청이 남으면 메뉴에 요약과 상세 진입만 제공한다.
상세는 현재 관측한 이름·요청 종류·확인 시각을 보여주며, 앱 연결이 확인된 항목만 `앱 열기`를 제공한다.
설치되었거나 실행 중이라는 사실만으로 목록에 올리거나 충돌로 표시하지 않는다. 조회 실패는 별도 상태로 표시한다.
이 상세에는 다른 앱 종료·제거·요청 강제 해제 조작을 두지 않는다.

## 이번 native 연결

- 설정은 `전원·덮개 / 수동 유지 / 보호·진단 / 일반` 4페이지로 구분한다. 전원 분리 정책은 전원·덮개에서 한 번만 편집한다.
- 시간 선택/시작은 메뉴에 통합하고, 직접 입력·끝날 시각은 별도 초안 sheet에서 명시 시작한다. 메뉴의 시간 행과 추가 링크 사이에 큰 별도 섹션 여백을 만들지 않는다.
- 추가 옵션 목록은 연결됨/일부 지원을 구분하며 미지원·검토 중 후보는 처음에 접는다. 미지원 기능에 실행 버튼을 만들지 않는다.
- 다음 수동 작업 기본값은 수동 유지 페이지에서 명시적으로 적용한다. 알림·설정 이동·사건 실행은 독립 상세 화면으로 연다. 펼치거나 취소하는 행위는 저장/작업 시작이 아니다.
- 현행 메뉴 폭과 설정 크기는 [스타일 가이드](../DESIGN.md#크기와-정렬)를 따른다. 긴 한글·영어 문구, 고대비, 스크롤, 키보드 포커스는 해당 후보 화면에서 확인한다.
