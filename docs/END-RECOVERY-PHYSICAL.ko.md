## 남은 별도 검증·출시 결정

- 실제 Sleep 판정에는 **성공한 OS 로그 조회와 해당 구간 Sleep/Wake**가 필요하다. 명령 수락·SleepDisabled·수집 공백만으로 통과시키지 않는다.
- 사용자 임의 잠금·macOS 명시 잠자기·Tether 잠자기와 충돌 앱은 기본 조작 중 자동으로 실행하지 않는다. 필요하면 에이전트가 별도 단계로 준비하고 사용자는 필요한 깨우기·정상 인증만 한다.
- 실제 macOS26·다른 Apple Silicon 모델·데스크톱은 이번 macOS27.0.1 MacBook 결과와 별도 인수다. 사용자에게 새 기기를 구하도록 요구하지 않는다.
- 전체 요소 배치 정량 채점과 실제 다른UID 파일 권한 경계는 별도 범위로 남아 있다. 완료된 기능회귀/UI18개와 혼동하지 않는다. 현재 사용자가 할 덮개/전원 조작에 추가하지 않는다.
- 공개 배포·실제 Sparkle 업데이트·실패 원복은 사용자가 정한 **마지막 단계**에서 에이전트가 진행한다. localhost 합성 업데이트가 실제 배포 업데이트를 대신하지 않는다.

기본4개와 사용하는 원격/주변기기 경로의 실제 로그를 바탕으로 실사용 승격 여부를 결정한다. 실패가 있으면 에이전트가 재현·수정·회귀를 처리하고 영향받는 물리 단계만 다시 요청한다. 로그로 확인되지 않은 잠금·입력·Sleep은 미확인으로 남긴다.
