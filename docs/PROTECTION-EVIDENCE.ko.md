# 보호 기준과 근거 — 빌드 49

2026-09-30. 현재 보호는 macOS가 공개적으로 제공하는 발열 상태와 사용자가 정한 잔량·시간 예산을 따른다. 임의의 배터리 섭씨 제한과 자동 전원 모드 변경은 제거했다. 실제 기기 수명·안전 인증과 소프트웨어 동작 시험은 다르다.

| 입력/정책 | 근거와 현재 처리 | 한계 |
|---|---|---|
| OS `serious` / `critical` | Apple은 심각에서 작업량 축소, 위험에서 CPU/GPU/I/O 최소화를 안내한다. Tether는 다음 관측에서 자체 유지를 중지한다 | 신호의 의미는 공식 API다. 자체 유지 중지는 Tether의 제품 정책이며 모든 발열 원인의 진단을 뜻하지 않는다 |
| `nominal` / `fair` | 보호 중지 후 직접 재개할 때 허용하는 상태 | 냉각만으로 자동 재개하지 않는다 |
| 잔량 기본 20%, 선택 상한 80%; 재개 하한 +5% | 남겨 둘 배터리 예산과 반복 경계 방지 여유 | 제조사 배터리 손상 경계가 아니다 |
| 공유 최대 4시간, 설정 최소 30분 | 첫 배터리 유지부터 중지·절전 시간을 포함해 단조 시계로 계산한다 | 제조사 안전 시간이 아니다. 전원 복귀 연속 관측 30초 후 새 예산 허용 |
| 배터리 섭씨값 | 기기별 센서를 읽을 수 있을 때 진단에만 사용한다. 누락·비정상 숫자가 유지나 JSON 기록을 깨뜨리지 않는다 | Apple의 주변 환경 10~35°C를 배터리 센서 제한으로 환산하지 않는다 |
| AC에서 잔량 하한 이하 + 방전 전류 -100mA 이하 60초 | Tether가 직접 유지하는 닫힌 상태에서 배터리 소진 방지 | 전류/시간은 공학적 잡음 억제 기준이며 충전기 불량 진단이 아니다. 충전하지 않음만으로 오류 판정하지 않는다 |
| 화면 복구: 10초 간격, 사건당 최대 3회 | 연속 재점등과 무한한 화면 끄기 경쟁을 제한한다 | 화면 명령 성공은 패널 전력 차단 증거가 아니다 |
| 정상 화면 절전 60초, 표본 간격 최대 10초 | 별개의 나중 깨움을 새 사건으로 다루기 위한 관측 창 | 하드웨어 수명 기준이 아니다. 공백·미확인·단일 성공으로 예산을 갱신하지 않는다 |
| 화면 연속 조회 실패 10초 | 추가 유지를 중단하고 원인을 남긴다 | 미지원/일시 실패를 화면 꺼짐 성공으로 바꾸지 않는다 |
| 기본 점검 30초, 활동 중 3초, 이벤트 합치기 0.1초 | 이벤트를 주 경로로 쓰고 누락을 주기로 보완한다 | 기기별 최적 소비전력 주기라고 검증한 것은 아니다 |
| watchdog 점검 30초 / 도우미 무응답 90초 | 현재 부팅의 소유 기록을 확인한 뒤 자체 변경 복구 | launchd 지연·절전 때문에 실제 복구는 늦어질 수 있다. 잠자기 명령과 실제 Sleep은 별도 확인한다 |

AC + 외장/가상 화면에서 Tether가 추가 유지를 하지 않으면 발열·화면 관리도 macOS에 맡긴다. 저전력/고성능 모드·팬·충전 제어는 제공하지 않는다. 옛 모드 변경 기록이 있을 때만 기존 값 복원을 시도하고, 다른 주체가 바꾼 현재 값은 보존한다.

원본 온도 설정은 schema 3 이관 백업에 남긴다. 온도 기준을 직접 설정했던 사용자는 새 정책으로 자동 운용을 이어가지 않고 명시적으로 재개한다. 2026-10-02 정리에서 퇴역한 `LegacySafetyPolicy`와 `Advisor` 엔진을 제거했다. 구버전 자동 추천의 배터리 시간 한도만 `SettingsMigration` 내부에서 한 번 고정하며, 이전 사용자 한도보다 느슨해지지 않는다. 원본 필드의 읽기와 복구 백업은 유지한다.

공식 자료: [Apple serious](https://developer.apple.com/documentation/foundation/processinfo/thermalstate-swift.enum/serious), [Apple critical](https://developer.apple.com/documentation/foundation/processinfo/thermalstate-swift.enum/critical), [Mac 전원 모드](https://support.apple.com/en-us/101613), [온도와 통풍](https://support.apple.com/en-us/102336). Serious/critical 본문과 전원 모드 안내를 이번 작업에서 다시 확인했다.

열 보호 시험에는 모의 발열 입력을 사용하며 실제 기기를 가열하지 않는다. 물리 덮개·전원 시험은 OS Sleep/Wake 로그와 연속 표본으로 별도 판정한다. [최종 범위와 검증 경계](FINAL-SCOPE.ko.md).
