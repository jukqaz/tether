# V5 명세·화면 재검수

2026-10-16 · 명세와 HTML 시안만 수정 · 앱 미적용

결론: 종료·복구 계약의 충돌 다섯 가지를 정리하고, 화면 문구를 ‘무엇을 계속하고 언제 끝내는지’ 중심으로 바꿨다. 기존 조사에서 채택한 41개 기능 묶음은 명세·체크리스트·시안 기능 목록에 각각 연결되어 있다. 이는 세부 화면 전체의 완성이나 실제 앱 구현·기기 지원·물리 시험 합격을 뜻하지 않는다.

## 명세에서 바로잡은 규칙

| 발견한 문제 | 정리한 규칙 |
|---|---|
| 종료 행동 허가는 15초인데 디스크 해제는 30초까지 기다릴 수 있었음 | 종료 정리는 전체 60초, 디스크 단계는 일반 30초/보호 5초. 정리를 마친 뒤 원인·새 작업을 재확인하고 15초 행동 허가를 한 번만 발급. 늦은 완료는 예전 잠자기 실행 근거가 아님 |
| 새 작업을 확인하기 전에 디스크를 해제할 수 있었음 | 각 볼륨 해제 직전에도 새 작업·전원/소유자 변경·사용 중 상태를 확인. 새 작업이면 시작하지 않은 해제와 예전 잠자기를 취소 |
| 화면·덮개를 켜도 현재 작업에는 적용되지 않아 버튼 의미가 모호했음 | 주 스위치는 지금과 다음 작업의 명시적 변경. ‘앱 기본 따름’만 갱신하고 개별 선택은 보존. 끄면 해당 기능 실행을 회수. 시간·작업 ID·전원 조건은 그대로 |
| 추천 설정의 최대 시간 변경과 현재 작업 보호 강화를 혼동했음 | 추천 설정 변경은 다음 작업부터. 현재 작업의 최대 시간 변경은 별도 조작. 배터리 최대 시간은 직접·자동·연결 작업 모두에 적용 |
| 서비스 재시작 금지와 업데이트 시 작업 인계가 서로 모순처럼 읽혔음 | 예기치 않은 재시작은 이전 작업을 끝냄. 검증된 계획 업데이트만 같은 작업·원래 종료 시각·배터리 기준점을 인계 |

처음 설치하면 자동 시작·화면 켜두기·덮개 닫아도 계속은 꺼져 있다. 직접 시작 기본 30분, 배터리 기본 최대 2시간, 전원을 빼거나 앱을 종료하면 Tether의 잠자기 방지를 모두 끝낸다. 실제 프로그램·빌드를 강제 종료하는 동작이 아니다. 기존 사용자 선택은 새 기본값으로 덮지 않는다. 시안의 켜진 스위치는 사용자가 선택한 예시다.

시간 만료의 기본은 ‘상황에 맞게’, 닫힌 채 전원 분리의 기본은 ‘남은 작업이 없으면 설정을 되돌린 뒤 잠자기 요청’으로 따로 표시한다. 잠자기 요청과 실제 잠자기 성공은 구분한다.

## 읽기 쉬운 표현

| 이전 표현 | 화면에서 쓸 표현 |
|---|---|
| 유지 / 자동화 / 앱 | 잠자기 방지 / 자동 시작 / 앱 설정 |
| 수동 종료 | 타이머 끝내기 |
| 전원 범위 | 작동할 전원 상태 |
| 요청별 전원 범위 재평가 | 작업별 전원 설정에 맞춰 계속 |
| 원복 | 변경한 설정 되돌리기 |
| 예행연습 | 동작 미리 보기 |
| 자연 만료·상한 | 정한 시간이 끝남·최대 시간 |

[표시 문구 기준](COPY-V5.ko.md)에 의미 구분을 남겼다. 시간 종료와 전체 중지, 화면 끄기와 로그인 잠금, 권한 준비와 실제 동작을 같은 뜻으로 합치지 않는다. 기술 식별자·시계·소유권·서비스 세대는 개발·검증 계약에 보존한다.

## 시안에서 수정하고 확인한 것

- 자동 시작 전체 허용과 개별 조건 켬·끔을 함께 반영. 전원 연결 조건이 꺼졌다면 타이머 종료 뒤 자동 유지 중으로 표시하지 않음.
- 다른 설정을 바꾸거나 화면을 다시 그려도 선택값을 보존. 15분 시작·연속 연장·무제한 표시를 선택한 값에 맞게 변경.
- 종료 날짜/시각을 따로 입력하고 지난 시각은 거절. 적용 전까지 현재 시각은 그대로이며 자동으로 내일로 넘기지 않음.
- 동작 미리 보기는 선택한 전원 분리·닫힌 상태 종료 동작을 반영. 실제 전원·잠자기·센서를 조작하지 않음.
- 전원 연결 조건/개발 조건/새 조건은 각각의 이름과 전원 조건으로 편집. 여러 조건은 ‘모두 만족하는 묶음 / 어느 묶음이든 만족’으로 구분.
- 첫 설정에서 덮개 기능을 골랐다는 이유로 준비 완료로 표시하지 않음. 미준비면 적용을 막고, HTML에서는 별도로 표시한 ‘준비가 끝난 예시’만 제공.
- 현재 작업 설정의 ‘앱 기본 따름 / 이 작업에서 요청 / 요청 안 함’을 구별. 변경 후 메뉴 목록도 갱신하고 남은 시간은 보존.
- 고정된 예전 시간/미리 보기 안내 두 벌을 제거. 발열 기준·입력 유휴 시간·배터리 보호 선택을 명세와 맞춤.

## 아직 하지 않은 것

기존 앱 입력 파일 360개의 SHA-256은 보존 기준과 모두 같았다. JavaScript 구문·문서 로컬 링크·공백 검사도 통과했다.

V5의 [제품 검증 체크리스트](V5-VALIDATION-CHECKLIST.ko.md)는 그대로 `not_run`이다. 이 문서의 확인은 HTML 모의 화면과 명세 대조다. 앱 소스·설치본·전원·로그인 잠금·기기 설정은 변경하지 않았으며 native Liquid Glass, 실제 Sleep/Wake·덮개·전원 분리·도우미·업데이트 동작을 시험하지 않았다. 팬·충전·가상 화면 등 기기 확인이 필요한 기능의 지원 범위는 실제 검증 전까지 확정하지 않는다.
