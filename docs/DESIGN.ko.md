# Tether 디자인 문서 안내

현재 디자인 기준은 다음 세 문서로 관리한다.

- [스타일 가이드](../DESIGN.md): 시스템 색·서체·간격·네이티브 컴포넌트·검수 기준. 현행 치수는 스타일 가이드의 규격표를 따른다.
- [화면 정보 구조](DESIGN-V5.ko.md): 단일 메뉴와 사이드바 설정 4페이지, 상태·펼침·스크롤.
- [표시 문구](COPY-V5.ko.md): 허용 옵션과 실제 적용 상태, 한국어·영어 용어.

과거 3탭·360pt 메뉴·800×660pt 창 계약은 현행 기준으로 사용하지 않는다. 날짜별 검수와 설치·물리 시험 결과는 해당 보고서의 후보에만 유효하며 [문서 안내](README.md)에서 찾는다. 이 안내는 새 설치나 실제 전원 시험 완료를 뜻하지 않는다.
