# 화면 판정 개선 — Tether 2.2.0 빌드 30

실제 시스템 조회: 2026-09-28 15:00:53 KST. 전원 설정·화면 구성·원격 앱은 변경하지 않았다.

## 확인한 원인

기존 코드는 CoreGraphics의 ‘내장 화면인가’만 확인했다. 따라서 모든 비내장 화면을 `externalUnverified`로 묶었고, Splashtop의 가상 화면도 실제 외장 모니터와 같은 설명으로 표시했다.

현재 Mac에는 다음 3개 화면이 온라인으로 관측됐다. 추가 화면 두 개는 이름뿐 아니라 현재 화면 ID·제조사·제품 ID가 시스템 정보와 모두 일치했다. 조회 오류는 없었다.

| 이름 | 판정 | CoreGraphics 보고 크기 | 근거 |
|---|---|---|---|
| Color LCD | 내장 화면 | 1800 × 1169 | 시스템 정보·현재 식별값 일치 |
| Splashtop Display 1 | Splashtop 가상 화면 | 2560 × 1440 | 시스템 정보·현재 식별값 일치 |
| Splashtop Display 2 | Splashtop 가상 화면 | 1920 × 1080 | 시스템 정보·현재 식별값 일치 |

Splashtop은 [Mac 가상 화면 기능](https://support-splashtopbusiness.splashtop.com/hc/en-us/articles/43559930853275-Mac-Virtual-Display)을 제공한다. 이 Mac에서 관측한 vendor `0xeee0`, product `0xeee1`·`0xeee2` 패턴은 로컬 이름 대조로 확인한 것이다. 모든 버전의 공식 고정 ID라고 간주하지 않는다. 현재 화면이 가상 화면이라는 근거이며 실제 원격 사용자가 연결되어 있다는 증명은 아니다.

## 반영한 변경

- 일반 ‘유형 미확인’ 라벨을 없애고, 확인한 화면 이름·연결 방식·크기·절전 상태를 먼저 보여준다.
- 시스템 정보와 실시간 CoreGraphics 목록의 ID·vendor·product를 함께 대조한다. 화면이 분리되거나 ID가 바뀌면 이전 이름을 잘못 붙이지 않는다.
- HDMI/DisplayPort 등 유선, USB, AirPlay/Sidecar, 확인된 Splashtop 가상 화면을 나눠 설명한다. DisplayLink/USB 화면을 일괄 가상 화면으로 분류하지 않는다.
- 원격용 가상 화면만 있을 때는 ‘원격 화면 연결 중’으로 표시한다. 실제 외장 모니터의 기본 클램쉘 조건이라고 설명하지 않는다.
- 연결 정보가 제공되지 않아도 이름·온라인 상태 등 확인된 사실을 보여주며, 미제공·시간 초과·형식 변경·화면 전환·CoreGraphics 오류는 ‘판정 근거 보기’에서 구체적으로 설명한다.
- ‘화면·앱 상태 점검’에 현재 판정과 동작 이유를 함께 표시한다. 추가 화면이 있으면 클램쉘 화면에서도 바로 열 수 있다.
- 상세 시스템 조회는 점검 시에만, UI 밖에서 실행한다. 4초·512KiB 상한을 두고 일반 보호 루프에는 외부 프로세스를 추가하지 않는다.
- 읽기 전용 `tether displays [--json]`을 추가했다. 관리자 도우미가 없어도 원인을 확인할 수 있다.

AC에서 가상 화면이 있는 경우 기존 추가 유지·전체 화면 끄기 제외 동작을 보존한다. 명시적으로 선택한 AC 발열 완화와 위험 보호도 유지한다. 물리 패널 절전과 원격 연결의 동시 성공을 보장하지는 않는다.

## 검증

- 단위 검사 230개 통과. 신규 13개는 식별값 대조, 16진 ID, DisplayLink/USB, 연결 타입, 오래된 프로필·ID 재사용, 파싱/조회 실패, 개인정보 제외, 가상 화면 정책을 검사한다.
- 실제 helper/CLI의 격리 통합 검사 55개 통과. 가상/혼합 화면의 전체 화면 끄기 제외와 AC 발열 완화·critical 보호를 추가 검증했다.
- 실제 Mac의 화면 3개를 새 CLI로 읽고 시스템 정보와 일치함을 확인했다. 원시 직렬번호·EDID·UUID는 진단 결과에 포함하지 않았다.

관측 결과와 화면 미리보기는 로컬 outputs 산출물에 포함한다.

실제 관리자 설치·물리 덮개/패널 전환·모든 가상 화면 공급자 지원 검증은 별도다. 정보가 없는 화면을 물리 외장으로 추정해 채우지 않는다. 현재 변경은 로컬 개발 빌드이며 공개 배포하지 않았다.
