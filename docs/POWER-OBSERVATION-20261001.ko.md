# 전원·덮개 조회 실패 대응

2026-10-01. 빌드 50 개발 후보이며 설치본은 빌드 49다. 실제 Sleep/Wake, 패널 소비 전력,
원격 화면·입력, macOS 15 및 전 기종의 동작을 이 결과로 통과시키지 않는다.

## 재현한 문제와 변경

격리된 실제 도우미/Unix IPC에서 덮개 조회 값을 누락시키고 유선 외장 화면을 연결했다.
기존 코드는 누락을 열린 덮개로 해석해 자체 절전 설정을 시험 해제하고 기본 클램쉘 위임을
보고했다. 실제 OS 쓰기는 dry-run이었다. `before-helper.log`에 재현 근거가 남아 있다.

- `Snapshot`은 덮개·SleepDisabled·FullWake의 조회 실패를 Optional로 보존한다.
  호환용 Bool은 표시 용도이며 OS 동작은 확인된 Optional 값에 의존한다.
- SleepDisabled의 `pmset -g` 대체 조회는 성공·시간 제한·프로세스 종료 및 정확한 단일
  `0/1` 행을 확인한다. 누락·중복·잘못된 값·실패·미종료를 false로 바꾸지 않는다.
- 새 전체 절전 설정 변경에는 덮개·절전 설정·FullWake 확인이 필요하다. 기존 유효 작업,
  세션 ID, 기한과 복구 기록은 일시적인 조회 실패만으로 삭제하지 않는다.
- 자체 설정 해제는 현재 SleepDisabled가 확인되고 자체 복구 기록이 있을 때 수행한다.
  이때 덮개·깨움 조회가 빠졌어도 해제할 수 있으나 자동 Sleep은 요청하지 않는다.
- SleepDisabled를 못 읽으면 자체 해제 완료를 보고하지 않고 기록을 보존한다. 확인이
  돌아오면 현재 의도에 따라 해제한다. 소유하지 않은 값은 해제하지 않는다.
- 명령은 성공했지만 직후 검증 조회가 실패하면 정확한 소유권 항목과 목표를 기억한다.
  같은 항목에 대한 다음 관측으로 확인하며 이를 외부 앱 변경으로 잘못 분류하지 않는다.
  프로세스가 종료되면 디스크의 소유권 기록을 기존 복구 도구가 처리한다.
- 기본 클램쉘 시험 해제에는 확인된 열린 덮개가 필요하다. Native 근거는 기존 연결·OS
  정책 검증도 모두 통과해야 한다. 조회 실패 중 전체 화면 끄기와 자동 Sleep을 보내지 않는다.
- 화면 복구 횟수와 중단 상태는 전원·덮개 조회의 공백으로 초기화하지 않는다.
- IPC는 기존 필수 Bool 필드를 유지하고 조회 가용성과 FullWake를 추가한다. 새 앱은
  구버전/형식 오류의 누락 필드를 확인된 상태로 승격하지 않는다. 상태 안내는 일반 작업
  유지와 덮개 지원 확인을 구분하고, 로컬 로그는 실제 누락 원인을 남긴다.

명시적 사용자 Sleep은 덮개 값을 요구하지 않지만 FullWake와 절전 설정은 확인해야 한다.
일반 사용자 앱의 독립된 IOKit 작업 요청은 기존 정책·보호·유한 기한을 그대로 따른다.
열·잔량·시간 보호를 우회하거나 시스템 잠금 값을 변경하지 않는다.

## 검증

- 전체 Swift 580개: Core 489 + 앱/업데이트 91. 제한된 실제 비관리자 native 7개가
  전체에 포함되며 실패·건너뜀 0개다.
- 배포 후보에 포함된 실제 도우미/격리 IPC 64개: 조회 실패 17, 기본 위임 12,
  일반 작업 10, 원격/화면 정책 25. OS 쓰기와 센서는 dry-run이다.
- 초기 회귀 재현은 실패했고 수정 후 통과했다. 중간 전체 검사에서 Native 표식의 기존
  호환 정책을 과도하게 제한한 회귀가 발견돼 바로잡았다. 최종 전체 검사는 통과했다.
- 실제 미리보기 앱의 수동 시작 과정에서 연결 누락을 발견했다. 미리보기 소켓이 dry-run임을
  확인한 뒤 앱의 실제 PID를 정상 IPC로 연결하도록 수정했다. 운영 소켓·관리자 설치 경로를
  사용하지 않는다. 실제 화면 검증 근거는 로컬 결과 보고서에 기록한다.

## 남은 한계

읽기 실패가 지속되는 자체 설정 해제는 확인 대기 상태다. 이를 완료나 다른 앱 충돌로
단정하지 않는다. SleepDisabled는 시스템 전역 값이므로 같은 값을 쓰는 모든 앱을 완벽히
식별하는 독점 소유권을 제공하지 않는다. 장시간 하드웨어 시험, 잠든 채 전원 연결,
원격 연결·화면·입력, 외장 연결 변화, macOS 15 및 실물 데스크톱·UPS 시험은 별도다.
이번 단계에서 설치·커밋·푸시·공개 릴리스는 수행하지 않는다.
